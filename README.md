# TravelSync-AI-Coordinated-Multi-Agent-Travel-Planner-with-LangGraph
TravelSync AI is a LangGraph-powered multi-agent travel planner that transforms natural language trip requests into complete travel plans. It coordinates flight, hotel, itinerary, and response agents to deliver personalized recommendations, optimized itineraries, and seamless travel planning in one intelligent workflow.

## How to run?

1. Create the Virtual Environment

'''bash
conda create -n travel python 3.11 -y
'''
2. Activate the Environment

'''bash
conda activate travel
'''

3. Install the Requirements

'''bash
pip install -r requirements.txt
'''
